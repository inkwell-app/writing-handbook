# Security

Report vulnerabilities in the handbook tooling or repository workflows to **security@inkwell.software**. Include the affected version or commit, reproduction steps using fictional input, and the expected impact. Do not post vulnerabilities, credentials or private drafts in a public issue. See the reporting information at <https://www.inkwell.software/security>.

This repository contains static documentation and local maintenance scripts. It does not receive, store or process your writing. Linked services have their own privacy and security policies.
