# Plan a draft

1. Copy the [project brief](../templates/project-brief.md). Write the audience and intended outcome before choosing a target length.
2. List the questions or dramatic turns the draft must resolve in the [outline](../templates/outline.md).
3. Mark dependencies: what must the reader know before the next scene or section works?
4. Draft one difficult unit first to test your assumptions. Revise the outline based on what you learn.
5. Name a baseline draft before requesting feedback. Bring two specific questions to the [feedback session](../templates/feedback-session.md).

**Finished when:** you can explain the project, locate its key turns, and name the next writing action. The outline can change; it is a working map, not a contract.

**In Inkwell:** use Plot for a screenplay and explore Canvas for structured prose. Find the current product and audience guides in the [resource directory](../README.md#find-the-right-inkwell-resource).
