# Prepare a handoff

1. Ask the recipient what they need to do with the file: read, annotate, edit or prepare production.
2. Preserve the source and fill in the [handoff manifest](../templates/handoff-manifest.md).
3. Export the agreed format. A readable PDF and an editable source solve different jobs; include both when required.
4. Open the exported file in the receiving tool. Check content and the formatting features the job depends on.
5. If the recipient will edit and return the file, test that round trip before relying on it.
6. Record limitations and agree on which version is authoritative.

**Finished when:** the recipient can perform the intended task, knows which version to use, and can see any limitations.

For screenplay handoffs, use the FDX Inspector and interoperability guide in the [resource directory](../README.md#find-the-right-inkwell-resource). Developers can use [screenplay-interop](https://github.com/inkwell-app/screenplay-interop) for reproducible test cases; those fixtures are not proof that every application preserves every feature.
